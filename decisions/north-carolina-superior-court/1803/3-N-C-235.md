# Sawyer

## Majority (npAYLOR, Judge.)

npAYLOR, Judge.
If one patent kps over upon another, and the latter patentee is in the actual possession of the pait covered by both for seven years, he will acquire the title - but if neither be in the actual possession, it will belong to the first patentee.
