# Quintz v. Quintz

## Majority (JOHNSTON, Judge.)

JOHNSTON, Judge.
The report ought to state every tiling the reference directs. Here it has noi stated the several periods when the money was received, but only that it was received between such a day and such another day. Let it be referred again to make that statement.
